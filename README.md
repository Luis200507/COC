# COC Automation

Use esse aplicativo para agilizar suas tarefas do portal.

## Instalação

Clique no botão verde acima, escrito "CODE" > Download ZIP

Logo após isso, extraia o arquivo zip baixado, e abra o arquivo **setup.exe** e siga os passos descritos:


```python
Fique atento à janela aberta, caso peça para "pressione uma tecla para continuar",
aceite e continue. Quando a instalação terminar, será limpo e pedirá sua chave
de licença entregue, e então só seguir com o uso normal:

- Insira sua chave (será necessário apenas no primeiro uso)
- Insira seu email e senha de login do portal, para que o robô acesse as atividades
- Escolha a matéria desejada
- Primeiramente, digite apenas o numero do primeiro módulo e pressione Enter
- E logo após, separadamente, digite até qual o módulo final.
```
